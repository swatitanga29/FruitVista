Train the models

Training compares Linear Regression, Random Forest, Gradient Boosting and a seasonal baseline on the same chronological split, keeps the best performer for each task and saves it as a new version. A run reads the stored history only; it never changes a record. This is the only place training starts.

Training can take a little while on a laptop; the page stays on the Model Performance view afterwards.
